## Product mechanics extracted

The mined product value is a staged file-handling proof model:

- Request control and baseline behavior are separate from upload acceptance.
- Upload acceptance is separate from stored filename, storage path, or retrieval path.
- Retrieval is separate from server-side interpretation.
- File read, transformed source disclosure, remote retrieval, uploaded-file inclusion, and executable interpretation are separate reportable outcomes.
- Fuzzer hits are triage until manually replayed against a baseline or negative control.
- Execution claims require command-result Evidence and cleanup context.
