# Obol v9.28 — Quiet Offline Caching and Update Notice

v9.28 continues Product Hardening with the service-worker and update-notice slice of the Offline and Browser Performance Platform.

## Scope

- cache the static Obol shell for repeat visits and offline use without an install prompt;
- preserve live navigation and human-run behavior when caching is unavailable;
- surface an available cached update through one dismissible, user-initiated refresh notice;
- keep workspace state browser-local and preserve the existing v8.8 workspace schema.

Implementation, item-specific proof, release documentation, and exact-head validation remain in progress on this release branch.
