## Evidence boundaries

v7.6 deliberately keeps the following states separate:

- LSASS protection changes versus credential extraction;
- dump/registry artifacts versus parsed secret material;
- DPAPI master-key material versus decrypted credentials;
- session discovery versus impersonation;
- plugin or trigger installation versus recovered KeePass credentials;
- certificate/hash/password material versus validated authentication;
- validated authentication versus remote execution;
- execution versus administrator/SYSTEM context;
- MSOL credential material versus DCSync capability or domain privilege;
- successful collection versus cleanup/restoration.

Terminal Evidence interpretation for the new owners filters stronger inherited facts unless the exact reviewed stage explicitly proves them.
