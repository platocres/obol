# Obol v7.6

v7.6 continues the Orange source-depth phase with the pinned `admin.md` source family.

The release will preserve the frozen v6.2 baseline, atomize useful admin-context branches into explicit source-fidelity units, reuse mature owners where their Run → Evidence → Next Steps → Report contracts are already complete, and add focused owners only where product behavior is genuinely missing.

The intended source scope includes LSASS credential extraction, SAM and LSA secret recovery, DPAPI and master-key handling, token/session impersonation, RDP session transfer, KeePass credential recovery, user-directory discovery, and hybrid AD Connect credential recovery. Canonical advancement is limited to `admin.md` parents that remain partial in the frozen baseline; historically implemented parents remain historical while gaining deeper atomic accounting.

Evidence must keep process/dump creation, hash/password material, authenticated access, token/session context, remote execution, privilege, and cleanup separate. Sensitive dump/registry artifacts and temporary tooling require explicit cleanup guidance where applicable.

Final release validation is bound to the exact release head; any later code or documentation change requires a new validated head before merge.
