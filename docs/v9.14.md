# Obol v9.14

v9.14 continues the Representative Tool Builder Set on top of the stable schema-driven Tool Builder Platform. The release begins with NetExec / nxc and is intended to burn down the remaining same-package representative builders that fit the same command-model, browser integration, and regression boundary.

The release must keep Obol browser-local and human-run. Builders may generate, explain, and copy commands, but they must not execute them. Generated commands and manual outcomes remain workflow activity until reviewed Evidence supports report-ready facts.

Implementation, queue accounting, item-specific Definitions of Done, README synchronization, and exact-head regression proof will be completed in this release branch and the single v9.14 release pull request.
