## Evidence contract

Hash recognition is not cracking success. Loading a hash is not cracking success. Tool startup is not cracking success. Wordlist or mask exhaustion refutes only the tested candidate space. An explicit recovered result supports offline plaintext recovery only; it does not prove the credential is valid against a service, provide authenticated access, or imply administrator/SYSTEM privilege.

v8.2 adds a conservative cracking Evidence profile for recognized Hashcat/John command activity. Only explicit crack/recovery output can advance the activity to supported offline recovery, and the only automatic outcome fact is a credential candidate. Reuse and access remain separate validation steps.
