# Obol v9.49 — Next Steps style delivery repair and design-token integrity

v9.49 fixes the presentation drift the runtime layer consolidation left behind and adds a
permanent guard so it cannot recur. It closes `ux-current-owner-style-delivery` (UI / UX
repair) and `qa-current-owner-style-guard` (Testing / visual QA).

## The defect

The Next Steps page lost its formatting during flattening. Two independent, consolidation-
induced drifts caused it:

1. **Orphaned companion stylesheet.** `assets/operator-route-current.js` — the current owner
   that renders Next Steps, Card, and Tools — was inlined into the startup application owner
   `assets/obol-app-current.js` by `tools/sync-app-current.js`. Because the inlined module
   runs at startup and publishes `OBOL_OPERATOR_ROUTES`, the historical `ensureOperatorRoutes88()`
   loader short-circuited at `if(window.OBOL_OPERATOR_ROUTES)return` **before** it reached
   `addStyle88('assets/operator-route-current.css')`. The stylesheet was therefore never
   injected, so every `operator-*31` hero, metric tile, mode bar, and recommendation card
   on Next Steps rendered with no border, background, padding, or grid.

2. **Undefined design tokens.** The flattened historical cascade in `assets/obol-current.css`
   references role tokens it never defines: `--muted` (~140 uses), plus `--card`, `--surface`,
   `--hover`, `--bad`, `--ok`, `--green`, `--gold`, and `--warn`. Each `color:var(--muted)`
   silently fell back to the inherited value, so muted captions across the whole app lost
   their dim role and hierarchy flattened.

## The fix

- **Current owners deliver their own presentation.** `assets/operator-route-current.js` now
  injects its companion stylesheet itself (idempotent, Node-safe), the same way the current
  dashboard route owner injects `assets/product-hardening-dashboard.css`. Inlining or further
  flattening can no longer separate the owner from its style. `assets/obol-app-current.js`
  is regenerated from that source through `tools/sync-app-current.js`.
- **Tokens defined once, in an always-loaded current sheet.** `assets/responsive-current.css`
  (loaded unconditionally at startup) defines the missing role tokens, each mapped to an
  existing base token (`--muted:var(--dim)`, `--card`/`--surface:var(--panel)`,
  `--hover:var(--panel2)`, `--bad:var(--danger)`, `--ok`/`--green:var(--accent)`,
  `--gold`/`--warn:var(--accent2)`). This is a current-owner sheet, so the frozen historical
  cascade and its equivalence proof are untouched.
- **Consistency pass toward the North Star dashboard.** The operator route surfaces adopt the
  dashboard's card language — panel-gradient backgrounds, rounded corners, soft shadow — and
  its green accent replaces the one-off cyan used for primary and active states, so Next Steps
  reads as part of the same system as Home, Report, and the dashboard at 1920×1080.

## The guard

`tools/validate-current-owner-styles.js` is a deterministic, browser-free validator wired into
`tools/scope-check.js` and `tools/release-preflight.js`. It proves the delivered-presentation
contract that the older per-owner validators could not see:

1. **Companion delivery** — every current route owner injects its own companion stylesheet, so
   consolidation can never orphan one again.
2. **Token integrity** — every `var(--token)` used without a fallback in the runtime-delivered
   stylesheet set resolves to a definition in that set (custom properties set inline by the
   owners at render time are recognized as defined).
3. **Class coverage** — every `operator-*31` class the current operator route emits has a
   backing rule in the delivered set; if the companion sheet is ever dropped from delivery it
   leaves the set and this check fails loudly.

`tests/run-v9.49-tests.js` is the release regression suite and includes the anti-regression
proof: it reconstructs the pre-fix state and requires the guard to reject it.

## No new sediment

The fix adds no versioned runtime layer. The stable current owners `operator-route-current.js`,
`operator-route-current.css`, and `responsive-current.css` are edited in place; the frozen v9.5
fragment ledger, its order fingerprint, and the single-stylesheet-owner contract are unchanged.
