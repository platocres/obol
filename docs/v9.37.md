# Obol v9.37 — Path three-mode rendering

v9.37 completes `ux-path-three-mode`: Next Steps now has three operator-facing views over one evidence-ranked Path model.

## What changed

- `assets/operator-route-current.js` still owns the Path route; no fake `app-v9.37.js` or versioned route layer was added.
- `C.nextStepsOverview34(...)` is normalized once into a Path model, then rendered as Simplified, Checklist, or Live Map.
- Simplified keeps the compact “best next move” scan path from v9.31.
- Checklist shows every ranked technique with lane, status, why, unlock impact, Open, and Add to Planned Work actions.
- Live Map renders the same action/unlock graph as an SVG with technique links, explicit pan/zoom controls, pointer drag, and wheel zoom.
- View mode, map zoom, and map pan persist in the browser-local `state.ui.operatorPath31` workspace state.
- Supporting methodology detail remains collapsed under the current Path owner instead of competing with the current decision surface.

## Contract

The release preserves Obol’s static, browser-local contract. The map is a navigation and planning view only: Evidence review, manual outcomes, queued intent, and report proof remain owned by their existing mechanics.
