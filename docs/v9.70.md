## Private source boundary

This release uses the complete private review-packet fallback as source truth: `platocres/obol-source-notes@agent/review-packets:data/review-packets/manifest.json` and the adjacent review packets. Public Obol only receives generalized proof chains, analyzer facts, placeholder request shapes, browser-workflow guidance, cleanup/reporting boundaries, and additive path mechanics. Raw course prose, target values, flags, answer strings, screenshots, exact payloads, credentials, and solution chains stay private.
