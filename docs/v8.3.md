## Operator integration

v8.3 reuses mature `tomcat-deploy`, `mssql-access`, `website-discovery`, and `zerologon-check` owners and adds focused version-gated owners for EternalBlue, Java RMI, Java deserialization, Log4Shell, ProxyShell, Veeam, and GLPI.

The source commands remain human-run only. Version or service discovery is context. A positive vulnerability check supports a vulnerability finding at that stage. Payload generation or delivery is not execution. A callback proves only the callback stage it explicitly demonstrates. Credential recovery remains credential material until separately validated. Access and privilege require their own proof.

Preflight identified one inherited delivery-readiness debt on the mature Tomcat card after the new source mapping made it part of the current mapped contract. v8.3 closes that debt by adding the explicit Evidence profile and execution-surface metadata to every Tomcat command, with a regression test locking the repaired contract.
