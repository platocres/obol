# Obol v10.12

## What changed

v10.12 is a product-hardening release that continues the operator scripts / LOTL track
(v10.06 restored script rendering; v10.11 added the exam-safe / LOTL metadata layer). This
release puts those snippets on the operator **Next Steps path**: relevant scripts are now
proposed by Evidence state, and the path offers an exam-safe / LOTL alternative wherever it
would otherwise recommend a rule-breaking tool.

- Added Next Steps path metadata to a curated set of scripts in `data/scripts.js`: `prereq`
  (facts that must hold, same `{all,any,none}` shape as an Orange methodology card), `produces`
  (facts the operator gains), `lane`, and a `pathProposable` flag. The referenced facts already
  exist in the Orange lane graph, so a snippet surfaces exactly when the same Evidence that
  grounds its lane is present.
- Marked the manual SQL-injection checklist (prereq `web.sqli_confirmed`/`web.parameterized`),
  the bash `/dev/tcp` sweep and PowerShell port sweep (foothold recon), and the LDAPSearch
  cookbook (domain foothold) as path-proposable.
- `assets/operator-route-current.js` now proposes path-relevant scripts **additively** on
  `#/path` — a dedicated "Exam-safe / LOTL script moves" panel below the Orange methodology
  cards, never replacing them — for every snippet whose prerequisites the current Evidence
  meets.
- When a ranked Orange card would recommend a rule-breaking tool (`sqlmap` and the like), the
  path now renders an inline **exam-safe / LOTL substitute** offer beside the best next move,
  linking straight to the hand-driven snippet that stands in for it.
- Script proposals and substitute offers deep-link to `#/tools/__scripts/<id>`;
  `assets/tools-library-current.js` opens and scrolls to the named snippet, and keeps it
  visible even when the exam-safe facet would otherwise hide it.
- The additive script layer honors the workspace exam-safe mode flag (`state.ui.examSafe`)
  introduced in v10.11: with exam-safe mode on, the proposed script moves narrow to exam-safe
  snippets.

Orange baseline cards remain intact and first — scripts are only ever added alongside them.
Obol remains static and browser-local: no backend, telemetry, account system, install prompt,
or automatic command execution. The proposed snippets stay offline, human-run copy/review
snippets; surfacing one on the path executes nothing.
