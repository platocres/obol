# Obol v5.1

v5.1 deepens the dedicated North Star Dashboard without changing the canonical methodology denominator.

## Focus

The Dashboard now exposes delivery debt at the mapped-workflow level so future development can see exactly which existing workflows still need one or more of these contracts:

- a runnable command contract
- an explicit copy/paste Evidence profile
- explicit execution-side metadata instead of fallback inference
- reporting traceability

The new drill-down is searchable and filterable by debt type. It is intentionally diagnostic: it does not create facts, change applicability, mark techniques successful, or inflate methodology completion.

## Compatibility

The release remains static, browser-local, review-first, and human-run only. Existing workspaces are forward-coerced to v5.1 and sanitized exports retain inherited secret redaction.

## Canonical baseline

The pinned 2025.03 methodology baseline remains 52 implemented, 49 partial, 26 gaps, 0 stale, 41% fully implemented and 80% represented.
