# Obol v9.93

## What changed

- Mines the `source-note-cluster-reporting-cleanup-and-remediation-guidance` queue item into public-safe reporting, cleanup, mitigation, redaction, and retest guidance.
- Folds the cluster into the existing `report-discipline` primary owner instead of creating duplicate finding, report-writing, remediation, screenshot, cleanup, or retest wrapper cards.
- Keeps technical proof cards as context only so exploit/session/tunnel details remain owned by their existing cards while report readiness is handled in one clear place.
- Adds a report-readiness analyzer for finding narrative, evidence chain, root cause, mitigation mapping, cleanup ledger, retest signal, and redaction review evidence.
- Adds four public Field Notes covering complete finding chains, cleanup ledgers, root-cause-bound mitigation, and redaction/retest gates.
- Advances Product Build Next to the private-heavy skills-assessment and walkthrough-heavy note cluster, leaving 34 pending notes across two private-heavy cluster review items.

## Product mechanics

- Adds `data/product-hardening/reporting-cleanup-remediation-guidance-cluster-v9.93.js`.
- Updates `report-discipline` with copy-only report guidance commands and proof expectations.
- Adds `reporting-cleanup-remediation-guidance-router` as the v9.93 feature ID.
- Adds a public-safe analyzer exposed as `OBOL_REPORTING_CLEANUP_REMEDIATION_ANALYZER_V993`.
- Hooks current Evidence intake so pasted report, cleanup, mitigation, retest, or redaction evidence can move the reporting path.
- Advances source-note cluster accounting to 522/556 reviewed and 34 pending.
- Keeps the remaining pending queue private-heavy and explicitly labeled so agents do not turn walkthrough/source-only material into public UI filler.

## Validation

- Adds `tests/run-v9.93-tests.js` as the current product contract.
- Updates `tools/scope-check.js` and `tools/run-historical-contracts.js` so the current-product gate runs the v9.93 test suite.
- The v9.93 suite checks existing-card enrichment, absence of duplicate wrapper cards, field-note bindings, analyzer redaction, intake integration, source-cluster ledger progression, Product Build Next handoff, report metadata, and downstream private-heavy cluster generation.
- The release test invokes `tools/validate-release-pr.js --repo-only --release-version=9.93`.

## Compatibility

Obol remains static and browser-local. This release does not add a backend, account system, telemetry, install prompt, or automatic command execution. Report guidance remains copy-only and requires visible Evidence before findings, cleanup, mitigation, or retest claims are treated as ready.
