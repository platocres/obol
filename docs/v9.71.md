# Obol v9.71 - action-spine guardrail and AD/MSF re-mining

## Summary

v9.71 corrects the bad v9.70 card shape and builds the next Product Build Next queue item.

The main product rule is now explicit: a primary Next Steps card is an action step with lessons attached. Lessons, field notes, note summaries, and proof-boundary explanations are welcome on cards, but they must support a concrete command or GUI-tool action spine. A lesson-only or methodology-only item belongs in field notes, analyzer guidance, report wording, or an existing action-bearing card.

This release also preserves the intended `why now` feature. Cards should explain why a tool or command is useful at the current lab moment. What is forbidden is vague internal filler such as `fills an unresolved methodology gap`, source-mining provenance, release cleanup copy, or `UNKNOWN` tool scaffolding.

- Adds tests that fail `UNKNOWN` implementation/tool rows, blank commandless primary cards, internal methodology-gap filler, and primary note-derived cards without a concrete command or GUI action spine.

## Why-now follow-up

Every primary card should receive a future why-now pass. The desired card shape is:

```text
Why this step now
Current evidence or path state -> missing proof boundary -> command or GUI action -> produced fact or next path decision.
```

That work should be treated as product hardening across the full card inventory rather than as release-provenance text attached to newly mined cards only.
