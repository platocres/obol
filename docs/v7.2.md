## Permanent proof boundaries

ACL or ACE discovery is routing context, not effective control. Object-control rights are not a successful mutation. A successful mutation is not credential material, ticket material, authenticated access, execution, administrator access, privilege, or domain control.

v7.2 keeps these stages separate in Intake and reporting:

- rights or ACL discovery;
- owner, DACL, group-membership, SPN, Key Credential, RBCD, logon-script, OU/GPO, or DNS configuration mutation;
- credential, certificate, hash, or ticket material;
- authenticated service use;
- remote execution;
- administrator/SYSTEM privilege;
- cleanup/restoration.

Password reset is deliberately treated as credential material, not proof that the new password was accepted anywhere. A GPO write or GPO link change is not proof that any endpoint processed policy. A DNS service restart after ServerLevelPluginDll configuration is not proof that a DLL executed. Temporary changes require separate restoration Evidence where practical; user-password restoration is never fabricated when the original password is unknown.
