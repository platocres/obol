## Source corrections

The pinned persistence source contains useful ideas but several command spellings are incomplete or ambiguous. v8.4 preserves those source variants in lineage while modeling corrected operator guidance:

- the Golden Ticket Mimikatz source line concatenates `/aes256` to `/sid`; v8.4 separates those arguments;
- the Silver Ticket Mimikatz line uses SID/domain values inconsistently; v8.4 uses the domain SID for `/sid` and the DNS domain for `/domain`;
- the Silver Ticket Impacket line omits `-spn`; v8.4 requires the exact service SPN so the result is service-scoped;
- Diamond and Sapphire source commands show password, NT hash, and AES key placeholders together; v8.4 treats them as alternative authentication materials and uses only what the operator actually holds;
- the source's `Saphire Ticket` spelling is retained in lineage while the operator surface uses `Sapphire Ticket`.
