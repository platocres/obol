# Obol v9.42 — Core ownership flattening

v9.42 continues the Runtime Layer Consolidation package by working on `runtime-core-flattening`.

This release is scoped to the core state and derivation ownership area. The goal is to replace the remaining exact-concatenation core owner with a stable current owner that preserves browser-local workspace migration, proof boundaries, applicability, ranking, progress accounting, and report readiness without executing the historical core fragment chain directly.

## What changed

- Added the v9.42 release scaffold for the core flattening pass.

## Preserved boundaries

v9.42 preserves the v8.8 workspace/runtime schema identity, human-run command contract, Evidence/report proof boundaries, Product Hardening Dashboard ownership, frozen v9.5 historical ledger, and one-open-release-PR workflow.
