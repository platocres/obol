## Release-quality invariant

`tools/validate-release-quality.js` renders the live Build Next model and fails whenever either higher-priority debt class is nonzero:

- implemented-quality repairs
- mapped-delivery repairs

The gate is called by `tools/release-preflight.js` and by the protected full `test` job. Canonical-gap expansion is therefore merge-blocked when delivery debt has reappeared, without relying on a release author to remember a version-specific assertion.

## Conservative Evidence boundaries

v5.9 preserves narrow proof boundaries:

- UAC: handler setup and `fodhelper.exe` startup do not prove elevation. Independent `whoami /all` output must show High or System Mandatory Level before an elevated-token/admin fact is created.
- EternalBlue: an explicit VULNERABLE result proves MS17-010 exposure only. An opened session proves remote execution only. SYSTEM requires explicit post-session identity output.
- Exchange ProxyShell: Exchange presence or PoC startup is not proof. Template/CVE evidence establishes vulnerability context and explicit shell/identity output is required for remote execution.
- GLPI: an exposed legacy htmLawed test endpoint is context only. Vulnerability and execution require explicit matching evidence, and no privilege is inferred.
- Java deserialization: banner/service discovery and ysoserial payload generation are not success. The independent listener must observe the unique `OBOL_JAVA_DESER_OK` callback before execution is recorded.
