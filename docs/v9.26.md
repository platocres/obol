# Obol v9.26 — Notes Disposition Review Wave 1

v9.26 begins the substantive review phase for the 556-note private source ledger without pretending the single `notes-disposition-burn-down` queue item is complete early.

## Scope

The release advances the reviewed-note denominator from 4/556 to 15/556 while leaving `notes-disposition-burn-down` queued.

The first review wave ends with:

```text
reviewed: 15
modeled: 11
private-reference-only: 4
superseded: 0
rejected: 0
pending-review: 541
total: 556
```

The Product Hardening item count does not increase in this release because the burn-down item remains incomplete until every staged note has a terminal disposition.

## Private review source

The raw HTB and OffSec ENEX material remains in the private `platocres/obol-source-notes` repository.

For review work, that private repo now has a bounded review-packet pipeline on its `agent/review-packets` branch. The pipeline materializes the Git LFS sources inside GitHub Actions and generates private review packets containing review text, headings, code blocks, source hashes, and opaque note IDs. Those packets exist to let agents review note substance rather than making decisions from note titles alone.

Review-packet content stays private. Public Obol receives only terminal disposition metadata, rationale, opaque source IDs, and rewritten derived guidance.

## Stable disposition ledger

`data/note-integration.js` remains the stable non-versioned owner and advances to schema 1.1.0.

It now owns explicit `reviewedDispositions` rows. Every reviewed row records:

- an opaque private-source note ID;
- a terminal disposition;
- the review wave;
- a substantive rationale;
- public derived-output IDs for modeled notes.

Modeled rows must link to at least one rewritten public output. Non-modeled rows must not publish derived output. The validator checks both directions of the lineage so a public Field Note cannot cite a source that is still pending or private-reference-only.

The stable owner also preserves the v9.25 four-note milestone as historical data, so later burn-down waves can advance current counts without rewriting what v9.25 proved.

## Review-wave decisions

v9.26 reviews eleven additional HTB source notes beyond the four v9.25 seed notes.

Seven are modeled into durable Obol guidance. They contribute lessons covering:

- client-side controls versus server-side authorization;
- preserving transformation order when fuzzing encoded values;
- separating persisted-input, readable-include, and execution proof in file-inclusion chains;
- testing path-normalization/filter assumptions incrementally and treating legacy bypasses as runtime-dependent;
- comparing authorization and security-filter behavior across HTTP methods;
- reporting command-injection remediation as a design and least-privilege problem rather than blacklist tuning.

Four reviewed records are kept `private-reference-only` because they are primarily navigation/index material, volatile extension-marketplace catalog material, lab-specific assessment output without a distinct new lesson, or tool-specific command-obfuscation catalog material that does not belong in Obol's default reviewable-command workflow.

## Public Field Notes

The public Field Notes projection grows from four records to ten.

New records are rewritten Obol-owned guidance. They do not contain flags, lab targets, raw course prose, raw ENEX paths, or copied walkthrough output.

The new notes are context-bound where useful:

- `curl` and web-fuzzing contexts receive request-method, encoded-payload, and traversal guidance;
- Path receives file-inclusion chain, path-filter, HTTP-method, and command-injection remediation context;
- report-oriented remediation remains guidance only and does not create findings or proof.

## Proof boundaries

Note-derived guidance does not create Evidence facts, mark Manual Outcomes successful, execute commands, or become report-ready proof.

A source note being `modeled` means the lesson has been normalized into the product. It does not mean any operator action described by that lesson succeeded in a current engagement.
