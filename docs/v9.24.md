# Obol v9.24 — Manual Outcome Platform

Obol v9.24 is the Product Hardening release for the Manual Outcomes track.

## Release intent

The release adds a stable, browser-local way for an operator to record a human-run action as successful, failed, blocked, or skipped without turning that assertion into Evidence. Manual outcomes may affect workflow state, queue state, triage, and Next Steps, but report-ready facts must still come from reviewed Evidence.

The coherent release package covers:

- `manual-schema`
- `manual-ui`
- `manual-success-unlocks`
- `manual-failure-triage`
- `manual-proof-report`
- `manual-queue-interaction`
- `manual-tests`
- `manual-all-cards`

## Compatibility boundary

Obol remains static, browser-local, copy-only, and human-run. This release must not add a v9.24-specific app, core, project-model, or style mini-runtime. Workspace/runtime schema remains v8.8 unless a separate migration is explicitly justified.

Generated commands and manual outcomes are activity. Reviewed Evidence remains the only source of report facts and proof.
