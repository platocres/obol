# Obol v9.48 — Evidence overlay chain restoration

v9.48 closes `cc-evidence-chain-restore`, the correctness defect v9.44 filed when it retired four unreachable Evidence overlays.

## The defect

The Intake overlays form a decorator chain: each reads the `analyzeTerminal` already published on an earlier `OBOL_INTAKE_*` global, wraps it, and writes the wrapper back onto `OBOL_INTAKE_V21`. `intake-v7.7.js` hooked `OBOL_INTAKE_V76`, but v7.6 (like its peers) publishes helper functions only — it never puts `analyzeTerminal` on `OBOL_INTAKE_V76`. So v7.7 returned at its `if(!T.analyzeTerminal)return` guard, published nothing, and broke `intake-v7.8`, `intake-v7.9`, and `intake-v8.2` in turn. In every load order the runtime produces, all four ran their guard and mutated nothing. The conservative Evidence they were written to add — no-credentials DHCPv6/ARP poisoning and unauthenticated coercion beyond v7.6, relay-SOCKS lateral movement, certificate movement, Windows local-exploit conditions, WebDAV coercion capture, and offline cracking — never reached production.

## The fix

The four historical overlays stay retired in the frozen ledger: v9.44 was correct that they can never execute, and its reachability/differential retirement proof is untouched. v9.48 instead re-homes their conservative Evidence onto the live chain through a stable current owner, `assets/intake-evidence-restore.js`. It reproduces each overlay's stage/proof/repair logic verbatim but hooks the correct live global (`OBOL_INTAKE_V21`), so every overlay reads and re-wraps the fully-assembled `analyzeTerminal` in the original intended order.

The restoration is a route-lazy current owner, not a frozen fragment and not part of the exact-concatenation Evidence bundle. `data/runtime-manifest.js` declares it through `evidenceRestore` metadata plus a `lazy.evidenceRestore` group loaded after `evidenceParsing` on the Evidence and Artifacts routes, so it decorates `analyzeTerminal` last. The frozen 327-fragment ledger, the 37-fragment Evidence bundle, workspace migration, command behavior, recommendation logic, and report lineage are all unchanged.

## The proof

`tools/validate-evidence-current-equivalence.js` now proves both milestones. It keeps the v9.44 retirement proof (the four overlays never publish their global and never mutate `analyzeTerminal` in the frozen chain, and the surviving chain is byte-identical to the full frozen chain), and it adds a restoration proof:

- a reachability pass confirms the restoration owner replaces `OBOL_INTAKE_V21.analyzeTerminal` — the exact step the broken subchain skipped — while the retired `intake-v7.7.js`, appended the same way, still cannot;
- a differential pass over an unambiguous per-family operator corpus shows the restoration adds the intended conservative Evidence across all four re-homed families while keeping every outcome-fact proof boundary intact (no escalation to relay success, available credentials, admin/SYSTEM access, remote execution, domain-admin, DCSync, or recovered plaintext).

`tests/run-v9.48-tests.js` is the release regression suite; the reachability assertion is the coverage that would have caught the original broken link.
