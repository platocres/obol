## Evidence boundaries

v7.0 preserves the project proof contract:

- a temporary `msDS-KeyCredentialLink` change is not credential proof;
- an explicit returned NT hash is reusable credential material, not authenticated service access or privilege;
- a successful account-attribute change is a directory mutation, not certificate issuance;
- a returned PFX/certificate is credential material, not authentication, access, administrator, SYSTEM, DCSync, or domain-admin proof;
- restoration is its own cleanup state and must not be inferred from the earlier mutation;
- an ESC14 or `altSecurityIdentities` observation is configuration/candidate evidence only;
- source-fidelity metadata never creates engagement facts.

The generic terminal parser intentionally stays conservative where two account-update commands are operationally ambiguous. Obol does not manufacture a cleanup or privilege fact merely because the command family was recognized.
