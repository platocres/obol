# Obol v9.39 — Faster regression gate and dashboard at-a-glance

v9.39 is a product-hardening release focused on developer velocity and dashboard clarity. It does not change the browser-local product contract.

## Highlights

- **Parallel historical contract runner.** `tools/run-historical-contracts.js` now runs the syntax-check phase and the full suite/validator set through a bounded worker pool of isolated processes instead of one at a time. Coverage is identical — every file is still syntax-checked and every `run-v*-tests.js` suite still runs — but the complete gate finishes roughly in proportion to the available cores, so ordinary commits and pushes gate faster. Historical suites are hermetic (they write only to unique `os.tmpdir` paths) and the validators are read-only, so concurrent execution is safe and deterministic.
- **Dashboard at-a-glance summary.** The Product Hardening Dashboard leads with a compact summary strip — release, product-hardening percent, notes reviewed, mechanic conversion, and the guidance-only backlog — so build status is legible at a glance before scrolling into the detailed ledgers.
- **Notes conversion metrics surfaced.** The Notes Integration detail now shows the v9.36 rubric: mechanic conversion (the primary notes metric), the ratcheted guidance-only backlog, and script-bound guidance counts. The README continues to link to the same queue and notes-impact data that feeds the dashboard.

## Layer retirement note

Physical retirement of historical runtime layers remains per-area lifecycle work (current owner → equivalence → fixture → live-layer removal → obsolete-test retirement), tracked by the `architecture-runtime` runtime items and the dashboard retirement matrix. This release makes the regression gate fast without deleting any layer, so no coverage is lost.
