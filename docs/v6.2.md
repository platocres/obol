The final canonical gap, `trusts.parent-child`, now has a dedicated delivery-ready parent-to-child trust workflow with explicit execution-side metadata, Evidence interpretation, decision-path placement, and reporting traceability.

## Parent-to-child trust proof boundaries

The upstream Orange source describes parent-to-child as the same family of path as child-to-parent. Obol makes the direction explicit rather than leaving it implicit. Trust relationship context, domain SID context, recovered trust secret material, saved Kerberos ticket material, successful child-domain service interaction, and privilege remain distinct facts. Ticket creation never silently becomes administrator or SYSTEM access.

## Canonical breadth versus Orange source depth

Zero canonical gaps does not mean every useful idea in the pinned Orange source has been extracted. The 127-section denominator is deliberately normalized. v6.2 therefore freezes the 34 partial canonical sections as a stable source-depth audit baseline and adds a separate Dashboard metric and Build Next phase for them.

See `docs/ORANGE-SOURCE-DEPTH.md` for the permanent plan. Each baseline item must eventually be explicitly classified as modeled, superseded by a better Obol path, or rejected with a reason. The source-depth audit examines subordinate branches, prerequisites, tool choices, failure states, artifacts, cleanup, GUI controls, Evidence, Next Steps transitions, and reporting rather than treating a broad card as automatic completion.

## Dashboard and Build Next

When implemented-quality debt, mapped-delivery debt, and canonical gaps are all zero, v6.2 promotes pending source-depth items into Build Next. North Star Dashboard remains the authoritative prioritized drill-down and the README contains the synchronized human-readable phase snapshot.

## Compatibility

Obol remains static HTML/CSS/JavaScript with no backend, build step, telemetry, or command execution. Existing browser-local state and sanitized-export behavior remain compatible through the additive v6.2 state overlay.
