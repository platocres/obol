# Obol v9.1.1

v9.1.1 is a documentation and release-contract cleanup for the post-Orange product-hardening phase.

## Summary

This release streamlines `README.md` so it works as a future-agent handoff instead of carrying old Orange data-build clutter, historical build statistics, and release-history material that belongs in durable docs or the changelog.

## README handoff

The README now focuses on:

- what Obol is;
- the current release and live site;
- the human-run/no-backend/no-telemetry product contract;
- the required future-agent quickstart;
- the required context map for build work;
- the active Product Build Next queue;
- validation commands.

Completed Orange methodology/source accounting is now referenced through `docs/NORTH-STAR.md` and `docs/ORANGE-SOURCE-DEPTH.md` instead of being duplicated in the README. The old historical methodology/source Build Next block is no longer rendered in the README while the Orange queue is empty.

## Product-hardening queue

The active Product Build Next block remains generated from `data/product-hardening/product-hardening-queue.js`. The Product Hardening Dashboard remains available at `#/dashboard` and `product-hardening.html`.

No product queue item is burned down by this release. It only improves the handoff surface so future agents land in the right queue and read `BUILDING.md` before changing release workflow.

## Validation added

v9.1.1 adds `tests/run-v9.1.1-tests.js` for README handoff structure, removal of Orange-era README clutter, durable-doc ownership of Orange accounting, patch-version release validation, and historical Build Next omission behavior.

It also updates:

```bash
node tools/sync-readme-build-next.js --check
node tools/validate-release-pr.js --repo-only --release-version=9.1.1
node tools/validate-historical-tests.js
node tests/run-v5.0-tests.js
node tests/run-v9.1-tests.js
node tests/run-v9.1.1-tests.js
```

## Compatibility

Obol remains static, browser-local, human-run, and no-telemetry. No backend, account system, automatic command execution, raw public note import, runtime overlay, or product queue disposition change is added.
