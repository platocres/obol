## Evidence boundaries

v7.8 keeps the proof contract conservative. In particular:

- possession of a credential, hash, ticket, certificate, or relay session is not authenticated service access;
- a relayed SOCKS session is transport/authentication context, not DCSync rights, file access, execution, or SYSTEM;
- SID output proves identity/domain information only;
- an MSSQL prompt proves database authentication only;
- returned account/hash rows are required before recording replicated credential material;
- remote command output is required before recording execution;
- SYSTEM or administrator context requires explicit returned identity/privilege Evidence;
- a PFX is credential material, not access;
- a returned TGT/ccache is ticket material, not downstream service access;
- a recovered NT hash is credential material until separately validated;
- an LDAP shell proves authenticated LDAP context only, not directory mutation or privilege;
- coercion, inbound authentication, relay success, service access, execution, privilege, and cleanup remain separate proof states.

Project/source accounting metadata never creates engagement facts.
