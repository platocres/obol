# Obol v9.59

## What changed

v9.59 fixes a stale Product Build Next handoff after the v9.58 proof/auth work landed. The generated README had advanced to `notes-remine-linux-privesc`, but Linux privilege escalation had already been mined into the public-safe Linux packet and current note guidance.

This release adds a small Product Hardening reconciliation extension that treats `notes-remine-linux-privesc` as complete only when the Linux privilege-escalation packet is already complete and the expected public Linux privilege-escalation guidance owners are present.

The result is that Product Build Next should stop sending agents back into already-completed Linux privilege-escalation work and advance to the real next remaining source re-mining item: `notes-remine-private-only-superseded`.

## Product Build Next queue sync

Queue correction is product work because the README and dashboard are the agent handoff. A stale top queue item sends future agents into duplicate work and makes the build loop less trustworthy.

v9.59 loads `data/product-hardening/linux-privesc-remine-reconciliation-v9.59.js` through `data/current-release.js` so release/runtime Product Build Next sync can evaluate the correction before rendering the generated queue block.

## Evidence and Next Steps boundary

This release does not add a new operator command, tool card, proof control, or terminal analyzer. It is a queue/progress reconciliation over existing Linux privilege-escalation guidance owners. Therefore it does not need new Evidence-ingestion parsing of pasted terminal output.

The existing v9.58 guard remains intact: when a future release adds a command, tool-card, proof-control, analyzer, or path item that expects pasted output, Evidence ingestion and outcome facts are part of the Definition of Done.

## Source boundary

No private note body, course prose, target, flag, credential, screenshot, exploit recipe, callback/listener mechanic, or exact solution chain is copied into public Obol.

The reconciliation cites only public-safe owner IDs and the complete Linux privilege-escalation packet state already represented by Obol.
