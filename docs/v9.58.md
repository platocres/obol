## Source boundary

This release uses the complete private review-packet route at `platocres/obol-source-notes@agent/review-packets` and keeps raw source text private. Public Obol receives only rewritten, generalized guidance and product metadata.

The release intentionally excludes raw secrets, captured values, ticket-injection recipes, relay or capture setup mechanics, target names, private keys, passphrases, flags, and course-specific replay steps.
