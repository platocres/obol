## Evidence analyzer

The new `pass-the-hash-output-analyzer` classifies pasted terminal output into separate proof states:

- PtH attempt observed
- NT hash material observed
- Windows process/token path observed
- remote admin indicator observed
- remote execution artifact observed
- auth failure or lockout signal observed
- token filtering or restricted-admin condition observed
- local-account scope observed

The analyzer is intentionally conservative. A hash-shaped value does not become access by itself, and a successful login or remote execution result stays scoped to the observed identity, host, protocol, service, and privilege level.
