## Delivery contracts

Each new owner has:

- runnable human-operated command planning;
- explicit Kali/Windows/target execution-side metadata;
- an explicit Evidence profile;
- conservative terminal-intake handling;
- reporting traceability;
- bounded verification and cleanup semantics.

Ticket creation proves ticket material only. It does not establish administrator or SYSTEM access. Skeleton Key and memssp require explicit success output. DCShadow startup/push text does not prove directory mutation; the v5.4 default uses a bounded `description` marker and explicit readback before marking the workflow successful.
