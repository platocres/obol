# Obol v10.10

v10.10 is planned as the Burp Suite first-class Tool Builder release.

## Build target

Burp Suite should not stay hidden behind legacy/example treatment. This release promotes Burp into the active web/request-helper Tool Builder surface as a guided third-party GUI workflow instead of pretending it is just another terminal scanner.

## Intended behavior

- Add a first-class Burp Suite guided workflow builder.
- Support proxy listener and browser setup guidance.
- Support target scope, sitemap, Proxy history, Repeater, Intruder, Scanner triage, and raw request/response import handoffs.
- Analyze pasted Burp Proxy history, HTTP request/response pairs, Repeater observations, Intruder rows, Scanner issue details, sitemap findings, and proxy/TLS failures.
- Preserve strict proof boundaries: captured traffic, Scanner alerts, reflected payloads, status changes, cookie changes, redirects, and different response lengths are leads until reviewed follow-up Evidence proves a specific claim.

## Compatibility

Obol remains static and browser-local: no backend, telemetry, account system, install prompt, third-party app control, or automatic command execution. Burp guidance remains human-reviewed guidance for authorized labs and engagements; Evidence remains the proof layer.
