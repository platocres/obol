# Obol v10.04

v10.04 is a product-hardening release for the modeled Tool Builder backlog, with Evidence ingestion treated as part of implementation rather than a later documentation pass.

## What changed

- Promotes Ligolo-ng into the schema-driven Tool Builder platform for proxy, agent, interface/route, tunnel, listener, and proof/cleanup workflows.
- Adds a stable current Tool Builder Evidence owner so Ligolo-ng decision-relevant output can return through Evidence and chisel/SSH/plink can prove shared analyzer coverage.
- Audits the existing chisel and SSH/plink tunnel builders against the v10.03 minimal-command contract so default previews stay small and optional behavior remains additive.
- Keeps tunnel creation as operator-reviewed command generation only. Proxy startup, agent connection, interface creation, route creation, tunnel start, listener state, connectivity, failure, and cleanup remain separate proof states.
- Requires independent connectivity Evidence before Ligolo route/tunnel setup can produce `pivot.route_established`; route setup alone does not imply reachability, access, compromise, or privilege.
- Makes executable Evidence ingestion, conservative proof boundaries, relevant Next Steps handoff, and regression fixtures part of the permanent implemented-tool Definition of Done.
- Repairs the release handoff after the merged v10.03 command-hygiene work left the public release authority on v10.02.

## Validation target

The release must prove direct Tools rendering for Ligolo-ng, minimal commands for the pivot builders, additive route/listener/transport controls, conservative Evidence ingestion for positive/negative/partial/cleanup states, recurring pivot-path handoff, and the exact-head release/browser gates.
