## Product output

The new Product Hardening extension is:

```text
data/product-hardening/web-proxy-transform-remining-v9.62.js
```

It publishes these public-safe field-note outputs:

- `note-client-controls-are-request-shaping-clues` — keeps disabled buttons, hidden fields, and browser-side checks separate from backend authorization proof.
- `note-encoded-cookie-transform-order` — preserves original value, decoded stages, mutation point, reverse-encoding order, final request value, and response comparison as separate evidence.
- `note-capture-tool-http-before-debugging` — tells operators to proxy and inspect generated HTTP before assuming a framework module, target path, or local configuration is wrong.

It also publishes the analyzer ID:

```text
web-proxy-transform-output-analyzer
```

The analyzer can classify pasted operator output into conservative facts such as:

- `web.client_control_mutation_observed`
- `web.reversible_transform_chain_observed`
- `web.encoded_cookie_candidate_observed`
- `web.payload_processing_or_response_delta_observed`
- `web.tool_generated_http_capture_observed`
- `web.scoped_server_behavior_observed`

Client-side mutation, transform construction, response-length deltas, and generated tool requests do not become impact proof by themselves. The workflow keeps scoped server behavior separate.

## Evidence and Next Steps boundary

This release adds Evidence ingestion for web proxy transform and generated request-capture proof chains. The analyzer is deliberately conservative:

- client-side control mutation only suggests a request-shaping or UI-control state;
- reversible decoding only suggests a transform chain that must be recorded and rebuilt carefully;
- payload processing and response-size deltas are triage leads until the response is reviewed;
- a framework or scanner run is only an attempted generated request;
- scoped server behavior must be observed separately before the workflow treats the action as impact.

The output is visible through path/web/proxy context as field-note guidance and through Evidence ingestion as an activity/fact classifier. It does not execute commands.
