# Obol v9.36 — Notes conversion rubric and script disposition

v9.36 is a product-hardening release. It captures the corrective-plan notes work since v9.35 and adds the script-bound note disposition.

## Highlights

- **Notes conversion rubric enforced (`notes-conversion-rubric`).** The notes-impact projection exposes a `rubric` over modeled notes — mechanic-backed, justified guidance-only, unjustified guidance-only, compliant, and `mechanicConversionPct` — and `tools/validate-notes-impact.js` ratchets the unjustified guidance-only backlog against a frozen ceiling so it can only shrink. Mechanic conversion, not review count, is now the primary notes metric (current state: 1/95, backlog 43/43).
- **Script-bound note disposition (`notes-script-category`).** A first-class `script` kind now runs end to end: `data/note-integration.js` atom kinds, the `data/field-notes.js` public contract, the notes-impact `script-guidance` impact type and count, and the `tools/validate-field-notes-ui.js` contract. Reusable one-liners and scripts derived from notes are tracked outputs instead of being folded into tool guidance.
- **Corrective-plan queue.** The Product Build Next queue carries the corrective roadmap (see `docs/CORRECTIVE-PLAN.md`): conversion rubric, re-audit backfill, script category, Path three-mode, and a UI audit rubric.

## Contract

The public product contract is unchanged: a static, browser-local study tool with human-run commands, no backend, no telemetry, and evidence-based proof separate from manual workflow advancement.
