# Obol v9.12 - Tool Builder Platform

v9.12 starts from the recommended Product Build Next package, **Tool Builder Platform**.

This release will establish the reusable schema, generic renderer, complete runnable-tool inventory lock, and permanent builder contract validation needed before Obol begins shipping representative tool-specific builders such as Nmap, NetExec, Hashcat, ffuf, and secretsdump.

The platform will remain browser-local and human-run. It will model command inputs, toggles, target/context autofill, credential modes, output handling, evidence expectations, manual outcome boundaries, and report lineage without executing commands for the operator.
