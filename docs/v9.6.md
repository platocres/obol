# Obol v9.6 - Runtime Consolidation Foundation

v9.6 begins the recommended **Runtime Consolidation Foundation** Product Build Next package from `runtime-current-entry`.

## Scope

This release is intentionally limited to the shared runtime/build-loading ownership area that can be made safer without deleting historical behavior layers:

- establish one stable browser runtime entrypoint for the existing ordered script chain;
- make one generated/runtime manifest the source of truth for browser and Node load order;
- move `tools/current-runtime.js` off its duplicated hand-maintained data/core arrays;
- add a deterministic historical load-order/equivalence gate before future compaction removes any historical runtime owner;
- keep CSS consolidation, deeper lazy-loading, and request-budget reduction queued unless they can be proven within the same blast radius.

The completed Orange 2025.03 methodology/source accounting remains closed historical material. v9.6 does not change Evidence semantics, command execution policy, report proof boundaries, or the v8.8 workspace schema identity.
