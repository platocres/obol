# v9.56 dashboard overflow hotfix

The v9.56 dashboard readability release fixed the vertical wall of dashboard content, but the first deployed layout still sized the dashboard shell against the full viewport instead of the workspace left after the Parameters sidebar. On a 1920x1080 desktop this caused page-level horizontal scrolling and pushed dashboard content off-screen.

This hotfix keeps the dashboard inside the available Obol workspace:

- dashboard content uses `width:100%` with a bounded `max-width` instead of `calc(100vw - 56px)`;
- metric grids use auto-fitting columns instead of a fixed six-column desktop grid;
- dashboard-level overflow is clipped while long detail tables keep their own contained horizontal scroll areas;
- the Parameters sidebar exposes the existing `Context details` summary on the dashboard route so users can collapse or expand it at desktop widths.

The release test asserts these layout protections so the dashboard does not regress back into a horizontal-scroll layout while future queue/schema metrics are added.
