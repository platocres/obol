## Evidence and operator boundaries

Trust discovery, SIDs, recovered trust or krbtgt material, forged tickets, foreign membership, credentials, coercion/delegation context, SQL links, and certificate paths prove only their own stages. Cross-domain authentication, service access, execution, administrator/SYSTEM context, Enterprise Admin membership, and other privilege require separate Evidence appropriate to those transitions.

Source-accounting metadata is project metadata only and never creates engagement facts. Saved tickets do not become accepted service access, a trust relationship does not become authorization, and a linked SQL server does not become host execution.
