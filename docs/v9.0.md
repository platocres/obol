# Obol v9.0 - Product Hardening Queue Foundation

v9.0 starts the post-Orange product-hardening phase. It does not reopen the completed Orange methodology/source-fidelity queue and it does not attempt to burn down the entire new product queue in one release.

## Summary

This release adds the durable governance system for the next build era:

- machine-readable product-hardening queue data;
- a standalone Product Hardening Dashboard entrypoint;
- README Product Build Next synchronization;
- validation for product-hardening queue shape and asset references;
- documentation for tool-builder coverage, notes integration, UX quality, and the product-hardening phase;
- an explicit private notes source pointer to `platocres/obol-source-notes`.

## Queue tracks

The queue tracks are:

- Critical correctness
- Architecture / runtime
- UI / UX repair
- Tool GUI builders
- Credential modes
- Manual outcomes
- Notes integration
- Offline / performance
- Testing / visual QA

## Notes source staging

The public Obol repo now points to the private source repo `platocres/obol-source-notes`. That repo stages two ENEX exports with 556 total notes and 1,326 embedded resources. Raw notes are private source material. Public Obol receives normalized, derived guidance only.

## Dashboard behavior

`product-hardening.html` provides a single quantified dashboard with high-level progress, bars, Build Next, private notes source status, detailed track ledgers, and the full seeded work ledger.

Future work should integrate this surface into the existing in-app dashboard/navigation after the current runtime entrypoint is consolidated. v9.0 intentionally avoids adding another brittle monkey-patch layer to the existing dashboard route.

## Validation

Run:

```bash
node tools/validate-product-hardening-queue.js
node tools/validate-asset-references.js
node tools/sync-product-build-next.js --check
node tests/run-v9.0-tests.js
```

These product-hardening checks are additive to the existing smoke, preflight, release-quality, README synchronization, and historical regression gates.
