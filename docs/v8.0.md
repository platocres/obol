## Evidence boundaries

v8.0 keeps the final baseline work deliberately conservative.

SCCM/PXE hash material, a recovered plaintext candidate, authenticated service use, execution, and privilege remain separate states. Hashcat output never becomes access by inference.

Zerologon detection proves only the reported vulnerable or patched condition. Obol does not add the pinned destructive machine-account password-reset exploit to the current operator surface. That source branch is explicitly superseded because an incomplete restore can damage the domain. Detection output therefore never becomes exploitation or Domain Admin proof.

A Domain Admin group-membership mutation is a directory change. It is not proof that the principal exercised privileged authorization, executed code, obtained SYSTEM, or completed a domain objective. Baseline membership, temporary addition, verification, later authorization, and cleanup remain separate Evidence obligations.

Project/source accounting metadata never creates engagement facts.
