# Obol v7.1

v7.1 continues the Orange source-depth phase by atomizing the pinned `delegation.md` family and carrying its useful branches through Obol's human-run command, Evidence, Next Steps, cleanup, lineage, and reporting contracts.

## Release scope

- decompose Kerberos delegation discovery, unconstrained delegation, constrained delegation with protocol transition, constrained delegation without protocol transition, RBCD, and S4U2Self into explicit source-fidelity units;
- preserve the pinned Orange 2025.03 source provenance and the frozen v6.2 source-depth denominator;
- keep ticket material, directory mutations, authenticated service access, execution, administrator access, and privilege as separate Evidence boundaries;
- improve the delegation operator surface instead of treating the legacy broad `delegation-abuse` card as source-fidelity completion;
- update the consolidated current-project model and generated Build Next accounting from one source of truth;
- remain delta-based and avoid redundant Dashboard or other no-op release shims.

The exact final release head must pass the repository release workflow before this PR leaves Draft.
